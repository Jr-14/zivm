# zivm
A zig version manager written in zig. Yes there are existing once, but I want to write one to use myself

# Usage

List available versions to install. This creates a network call
```bash
$ zivm list-remote
master
0.17.1
0.17.0
0.16.0
0.15.2
0.15.1
0.14.1
```
